☁️ Cloud Optimizations Implemented

⚡ Fault Tolerance: 2 App Service instances across Availability Zones with Application Gateway health probes for zero-downtime failover
📈 Autoscaling: CPU-based rules (scale out at >70%, scale in at <30%) with 2–5 instance range for elastic capacity
🔍 Advanced Monitoring: Application Insights collects request metrics, response times, failure rates, and dependency tracking
🔐 Security: NSG firewall rules, SQL Database IP whitelisting, private VNet, and managed identity authentication
